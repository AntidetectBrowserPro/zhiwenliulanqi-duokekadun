# 指纹浏览器多开卡顿怎么办？

「指纹浏览器」多开后变慢，先测是窗口太多、某个页面占用异常，还是网络响应慢。不同网页差异很大，同一台机器打开十张静态帮助页与十个视频后台不能直接比较。
[官网操作说明](https://zwbrowser.com/help/desktop/find-environment/)

![工作台中的环境名称与窗口操作](https://zwbrowser.com/images/desktop-guide-open-list-light.webp)

## 做一次阶梯测试

从一个演示环境开始，打开常用报表页并等待加载稳定，记下系统内存、CPU 与切换窗口的感觉。然后用同一页增加到两套、四套环境。Windows 可看任务管理器，Mac 可看活动监视器；保持其他应用和测试时间相近。

## 根据观察采取动作

只有某个报表窗口持续高占用，就先检查该页面和最近增加的脚本。内存随窗口数增加且切换开始明显迟缓，可以关掉不用的窗口，保留已保存环境供下次打开。若点击后只在请求数据时卡住，再检查线路和服务端响应。
